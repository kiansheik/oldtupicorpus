## What Worked

- Added `FADED_TEXT_PATTERN` plus helper functions in
  `scripts/xmlpage_to_html.py`.
- `%40 $raecepto%` now renders as a `.faded-text` span with
  `data-visible-percent="40"` and `--faded-opacity: 0.40`; `$` still becomes
  `ſ` before the faded marker is rendered.
- `strip_formatting_markers()` removes the `%XX` wrapper for width estimation,
  so the text content counts as visible but the markup characters do not.
- The underlying text remains in normal DOM text, so browser search can still
  find it.
- The CSS was added to both single-page and continuous-book HTML renderers.
- `docs/xmlpage-stylization-guide.md` now documents the syntax in Portuguese.
- `python3 -m unittest tests.xmlpage_to_html_test` passed with 23 tests.
- `git diff --check` passed.
