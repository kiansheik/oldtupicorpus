# Nominal Pro-Drop 3p Prefix Handoff

## Goal

Make a displaced explicit 3p subject/possessor in nominal contexts keep the
3p nominal prefix slot. The immediate target was the Araujo expression
`saguera((+jesus * ikobé) * îebyr)`, which should render with `sekobe...`
rather than bare `rekobe...`.

## What Worked

- `Verb.base_nominal()` now suppresses a displaced non-pronoun 3p subject while
  keeping `pro_drop=False` for conjugation, preserving the 3p nominal prefix.
- `saguera(jesus * ikobé)` still renders `Jesus rekobesagûera`.
- `saguera(+jesus * ikobé)` renders `sekobesagûera`.
- Existing pronoun precedents such as `saguera(+ae * ikobé)` and
  `saguera(+ae * gûeîyb)` continue to render with the expected 3p prefix.
- Araujo ground truth now includes the missed page-5 line in-place and updates
  the earlier affected nominal line to `i a'epe`.
- The broad `--skip-tokenizer` test run passes.
- The non-interactive Araujo ground-truth update path reports no new lines and
  no blocked sources.

## What Failed

- The first Araujo comparison after the code change failed at line 58 because
  the approved record still lacked the new `i a'epe` prefix.
- After editing only the legacy text file, the runner still failed because it
  prefers `ground_truth/records/historic/araujo_catecismo_1686.jsonl` when that
  structured record file exists. Updating both mirrors resolved the mismatch.
